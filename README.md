# GitHub Deployment Workflow

A simple static website deployment project using GitHub Actions and GitHub Pages.

## Features

- Deploys the website when index.html changes on the main branch.
- Uses GitHub Actions to automate deployment.
- Hosts the website using GitHub Pages.

## Technologies

- HTML
- Git and GitHub
- GitHub Actions
- GitHub Pages

## Website

The deployed website is available at:

https://YOUR_USERNAME.github.io/gh-deployment-workflow/

Replace YOUR_USERNAME with your GitHub username.
